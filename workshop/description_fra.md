[b]Mod côté client : n'affecte pas le déroulement de la partie.[/b]

[b]Vous empêche de terminer votre tour trop vite par erreur.[/b]
Chaque fois que vous gagnez de l'Énergie ou une carte supplémentaire, le bouton Fin de tour est verrouillé pendant un court instant.
Si vous gagnez de l'Énergie ou piochez une carte après avoir déjà appuyé sur Fin de tour, cela annule la fin de tour.
Un paramètre du mod vous permet d'ajuster librement la durée de ce verrouillage. La valeur par défaut est de 1,5 seconde.

[b]Fonction expérimentale : mode intelligent[/b]
Vous pouvez activer le mode intelligent dans les paramètres du mod. (Désactivé par défaut.)
Il vise à éviter que le bouton de fin de tour reste bloqué alors que vous n'avez plus rien à faire.
Si vous n'avez aucune carte jouable en main ni potion pouvant changer cette situation, la protection de fin de tour est suspendue.
Le mode intelligent est désactivé tant que vous possédez une potion qui n'existe pas dans le jeu de base.
Proposez des conditions supplémentaires dans les commentaires pour aider à améliorer cette fonction.

[b]Compatibilité des branches[/b]
Fonctionne sur la branche par défaut comme sur la branche Public Beta.

[b]Prérequis[/b]
BaseLib (installé automatiquement comme dépendance du Workshop).

[b]Langues[/b]
Le développeur est japonais ; en dehors du japonais, tout est donc traduit automatiquement. Les corrections sont très bienvenues.

[b]Retours[/b]
Les rapports de bugs et corrections de traduction sont les bienvenus en commentaire.
